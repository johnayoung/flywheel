| Data class                          | Definition                                                                                                                     | Key guarantees                                                                | Access pattern                                   | Retention                              | Target store                                                                                                     |
| ----------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------- | ------------------------------------------------ | -------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| **Operational (OLTP)**              | Reference/registry data, accounts, config, feature gates — the relational backbone the request path reads                      | Strong consistency, ACID, relational integrity                                | Small frequent reads/writes, row-oriented        | Life of the system                     | Relational OLTP database                                                                                         |
| **Ledger / Event**                  | System of record for business lifecycle events; the committed artifacts that make services stateless/replayable                | Append-only, immutable, never sampled, replayable                             | Sequential writes, occasional replay/audit reads | Years (regulatory/dispute horizon)     | Append-only tables in the relational DB → durable event log/streaming platform if multiple consumers need replay |
| **Decision analytics**              | Per-event decision traces, world-view snapshots, timings, plans — product data explaining *why* the system chose what it chose | Ledger-grade durability (1:1 with events, no sampling), but analytical access | Large scans, aggregations, time-bounded queries  | Years — product data, not exhaust      | Columnar OLAP database                                                                                           |
| **Market/world state — hot**        | The live external state a request is computed against (prices, upstream state, current conditions)                             | Latency-critical; freshness over durability                                   | Point reads at compute time                      | Seconds–minutes                        | In-memory key-value store / event-driven stateful service                                                        |
| **Market/world state — historical** | Snapshots (or pointers) of the exact state each decision consumed                                                              | Reproducibility — every decision references the state it saw                  | Scan-heavy, time-range queries                   | Years (reproduction/benchmark horizon) | Columnar OLAP database (alongside decision analytics)                                                            |
| **Telemetry**                       | Traces, logs, metrics — operational health signals                                                                             | Sampling/loss acceptable; aggregation-first                                   | Time-bounded dashboards, alerting                | Weeks (~30 days)                       | Time-series metrics store + tracing backend                                                                      |
| **Cache / Ephemeral**               | Derived/memoized data, dedup sets, rate-limit counters                                                                         | None — loss acceptable by construction                                        | Sub-ms key lookups                               | TTL-based                              | Shared in-memory KV store (when cross-instance correctness matters) / per-process memory (otherwise)             |
